# Psychometric Visual Explorer (PVE)

Professional psychometric analysis software built with Python and Streamlit.

## Purpose

Psychometric Visual Explorer (PVE) is a modern interactive application designed for psychologists, psychology students and researchers.

The application combines:

- Interactive psychometric analysis
- Statistical visualization
- Machine learning
- Educational explanations
- Modern dashboard interface

## Technology

- Python
- Streamlit
- Pandas
- NumPy
- SciPy
- Plotly
- Scikit-Learn
